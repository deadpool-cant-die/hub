# 바로 띄우기 (hub:show-me)

> 같은 폴더에 `reference.local.md`가 있으면 먼저 읽는다(회사·이 컴퓨터 전용: 레포·도구 경로·사람·채팅 번호). 공개 사본엔 없다.
> `HUB_SCRIPTS` = 이 플러그인의 `scripts/`(이 스킬 폴더 기준 `../../scripts`).

공통: 답은 짧게, 쉬운 한국어, 맨 앞에 `[HUB]`(레포 하나 얘기면 `[레포이름]`). **실제로 확인한 사실만** 쓴다(이슈 트래커, git, gh, hc, 메모리, TODO.md). 확인 못 한 건 "확인 못 함"이라고 적는다.

말로 설명하지 말고 **먼저 띄운다.** (사용자가 "보여 줘"라고 한 것이니 화면을 여는 건 허락된 일. 그 밖의 포커스 이동은 하지 않는다.)

## 찾기 (최근 것부터)
1. 이 대화·최근 보고에서 말한 결과물 경로·주소.
2. 최근 2시간 안에 바뀐 이미지·HTML·PDF: `find "$HUB_PRIVATE" ~/Documents ~/Desktop ~/Downloads -newermt "-2 hours" \( -name '*.png' -o -name '*.jpg' -o -name '*.html' -o -name '*.pdf' -o -name '*.mp4' \)` 와 worker 레포의 산출물 폴더.
3. 떠 있는 로컬 미리보기 서버: `lsof -iTCP -sTCP:LISTEN -P | grep -E 'node|python|vite|next'` → 주소.

## 열기
- 파일: `open <파일>`(이미지·PDF는 미리보기, HTML은 기본 브라우저). 여러 개면 비교용으로 함께.
- 주소: 브라우저 스킬(사용자 브라우저)로 열거나 `open <주소>`.
