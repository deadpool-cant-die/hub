# 칭찬 (hub:praise-me)

> 같은 폴더에 `reference.local.md`가 있으면 먼저 읽는다(회사·이 컴퓨터 전용: 레포·도구 경로·사람·채팅 번호). 공개 사본엔 없다.
> `HUB_SCRIPTS` = 이 플러그인의 `scripts/`(이 스킬 폴더 기준 `../../scripts`).

공통: 답은 짧게, 쉬운 한국어, 맨 앞에 `[HUB]`(레포 하나 얘기면 `[레포이름]`). **실제로 확인한 사실만** 쓴다(이슈 트래커, git, gh, orca, 메모리, TODO.md). 확인 못 한 건 "확인 못 함"이라고 적는다.

## 근거 모으기
`hub:what-did-i-do-today`와 같은 자료(오늘 커밋·머지·배포·티켓 완료·보낸 메시지·문서). 숫자는 직접 센 것만(머지 3개, 배포 2번 …).

## 쓰기
- 3~5줄. 구체적인 일 이름과 그게 왜 좋았는지(막힌 걸 풀었다, 사용자가 직접 결정해서 빨라졌다 등).
- 과장 금지("역대급", "완벽" 같은 말 X), 없는 일·없는 숫자 금지. 기록이 적은 날이면 적은 대로 솔직하게.
- 반말·존댓말은 평소 대화 말투를 따른다.

```
[HUB] 오늘 잘한 거
- <일> — <왜 좋았는지>
- …
<짧은 한 줄 마무리>
```
