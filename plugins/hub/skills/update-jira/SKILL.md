# 이슈 트래커 채우기 (hub:update-jira)

> 같은 폴더에 `reference.local.md`가 있으면 먼저 읽는다(회사·이 컴퓨터 전용: 레포·도구 경로·사람·채팅 번호). 공개 사본엔 없다.
> `HUB_SCRIPTS` = 이 플러그인의 `scripts/`(이 스킬 폴더 기준 `../../scripts`).

공통: 답은 짧게, 쉬운 한국어, 맨 앞에 `[HUB]`(레포 하나 얘기면 `[레포이름]`). **실제로 확인한 사실만** 쓴다(이슈 트래커, git, gh, hc, 메모리, TODO.md). 확인 못 한 건 "확인 못 함"이라고 적는다.

## 1. 오늘 한 일 모으기
`hub:what-did-i-do-today`와 같은 자료(커밋·PR·머지·배포·문서). 일마다 티켓 번호(PR 제목·브랜치·커밋·보고의 번호).

## 2. 빠진 것 찾기
티켓마다 오늘 댓글·상태를 읽고:
- 오늘 한 일이 댓글에 없음 → 댓글 초안(팀 양식 `진행: / 다음: / 블로커/결정:`)
- 완료 조건이 다 참(머지+배포+확인) → 완료로
- 상태가 실제와 다름(운영에 나갔는데 '할 일', 끝났는데 '진행 중') → 고침
- 티켓이 없는 일 → **새 티켓 초안만**(사용자 확인 전엔 안 만듦)

## 3. 시키기
이슈 트래커 담당 칸(이름은 `reference.local.md`)에 한 번에:
`hc send <담당> "[<나> → <담당>] 오늘 반영: <티켓> 댓글(본문 …) / <티켓> 완료(근거 …) / <티켓> 상태 → … . 새 티켓은 초안만 나에게."`
양식·규칙은 팀 스킬(`reference.local.md`) 그대로. 사실만, 비밀값 금지.

## 답
```
[HUB] 지라
댓글 N: <티켓> … / 완료 M / 상태 고침 K / 새 티켓 초안 L(확인 필요)
```
시험할 땐 3절을 보내지 않고 초안만 출력한다.
