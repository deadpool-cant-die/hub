# 기억하기 (hub:remember-this)

> 같은 폴더에 `reference.local.md`가 있으면 먼저 읽는다(회사·이 컴퓨터 전용: 레포·도구 경로·사람·채팅 번호). 공개 사본엔 없다.
> `HUB_SCRIPTS` = 이 플러그인의 `scripts/`(이 스킬 폴더 기준 `../../scripts`).

공통: 답은 짧게, 쉬운 한국어, 맨 앞에 `[HUB]`(레포 하나 얘기면 `[레포이름]`). **실제로 확인한 사실만** 쓴다(이슈 트래커, git, gh, hc, 메모리, TODO.md). 확인 못 한 건 "확인 못 함"이라고 적는다.

메모리 위치·규칙은 전역 지침의 "공용 메모리" 절(`<메모리>/MEMORY.md` 인덱스).

## 순서
1. **무엇:** 사용자가 방금 한 말에서 규칙·결정·선호 하나를 뽑는다. 원문을 그대로 인용할 문장을 고른다. 이번 대화에만 필요한 것, 코드·git에서 알 수 있는 것은 저장하지 않는다(그렇다고 알린다).
2. **있나:** `grep -ril "<핵심어>" <메모리>/*.md` + 인덱스 훑기. 같은 내용이면 그 파일을 고치고(바뀐 날짜·원문 추가), 반대 내용이면 옛것을 고치거나 지운다.
3. **쓰기:** 새 파일 `<메모리>/<type>-<kebab>.md`
   ```
   ---
   name: <파일 이름과 같은 slug>
   description: <한 줄, 언제 쓰는지 알게>
   metadata:
     type: feedback | user | project | reference
   ---

   <사실 한두 문장>

   **Why:** YYYY-MM-DD 사용자: "<원문>"
   **How to apply:** <언제 무엇을>. 관련: [[다른-메모리]]
   ```
   날짜는 절대 날짜. 비밀번호·토큰은 적지 않는다(위치만).
4. **인덱스:** `MEMORY.md`의 맞는 절에 `- [제목](파일.md) — 한 줄 요약`.
5. **규칙이면 문서에도:** Hub 운영 규칙이면 `~/Hub/AGENTS.md`, 특정 절차면 그 스킬 SKILL.md에 한 줄 넣는다. 전역 지침(`~/.claude/CLAUDE.md`)은 사용자가 직접 승인한 경우에만.

## 답
`[HUB] 기억함: <파일> — "<요약>"` (+ `AGENTS.md/<스킬>에도 넣음`)
