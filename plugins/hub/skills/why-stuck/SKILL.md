# 왜 멈췄나 (hub:why-stuck)

> 같은 폴더에 `reference.local.md`가 있으면 먼저 읽는다(회사·이 컴퓨터 전용: 레포·도구 경로·사람·채팅 번호). 공개 사본엔 없다.
> `HUB_SCRIPTS` = 이 플러그인의 `scripts/`(이 스킬 폴더 기준 `../../scripts`).

공통: 답은 짧게, 쉬운 한국어, 맨 앞에 `[HUB]`(레포 하나 얘기면 `[레포이름]`). **실제로 확인한 사실만** 쓴다(이슈 트래커, git, gh, hc, 메모리, TODO.md). 확인 못 한 건 "확인 못 함"이라고 적는다.

## 보기 (읽기만)
1. 일하는 세션: `python3 -I ${HUB_SCRIPTS}/status.py` → ▶·■ 세션마다 `hc read <이름> --lines 40`(무엇을 하고 있나, 무엇을 기다린다고 했나).
2. 그 세션이 기다린다는 것을 직접 확인:
   - PR 검사: `gh pr checks <번호>` / 실행 `gh run view <id>` — **이미 끝났는지** 본다.
   - 배포 실행: `gh run list -w <워크플로> -L3`.
   - 사람·리뷰 에이전트 답: 마지막 메시지 시각과 내용(읽기만, 방법은 `reference.local.md`).
   - 도구 오류·한도: 화면의 오류 줄, 429·usage limit.
3. 지시가 엇갈렸는지: 최근 그 세션에 온 지시 두 개가 서로 반대인지(hc 기록·보고).

## 답
```
[HUB] 왜 멈췄나
- <일> — <기다리는 것> (<근거>)  ← 검사 대기 / 사람 답 / 지시 충돌 / 도구 오류 / 한도
⚡ 이미 끝남: <일> — <무엇이 끝났는데 안 넘어갔는지> → <누구에게 넘기라고 보냄>
```
- 끝났는데 기다리고 있으면 그 세션에 바로 `hc send`로 알린다(보고처 경유 규칙대로).
